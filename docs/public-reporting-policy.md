# Public Reporting Policy

This repository is documentation-first and disclosure-restricted.

## Allowed Public Content

- project updates
- scope changes
- process notes
- repository names in the scan ledger
- public-facing documentation improvements

## Disallowed Public Content

- vulnerability writeups
- technical exploit details
- sensitive reproductions
- private report excerpts
- evidence that materially helps exploit a third-party system

## Public Scan Ledger Rule

The public ledger may list:

- repository name
- ecosystem or category
- public note such as `scanned`

The public ledger may not list:

- vulnerability descriptions
- severity
- root cause
- file paths
- reproduction detail
- exploitability notes

That separation is deliberate.
