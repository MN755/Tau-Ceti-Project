# Mission

Tau Ceti exists to improve software security by focusing attention on important, widely used software.

The public side of the project is intentionally narrow. It communicates:

- what the project is
- what it scans
- how the public repository is meant to be used
- which repositories have been scanned

The public side does not serve as a vulnerability publication feed.

## Public Principles

- Keep the public record useful and restrained.
- Do not turn unpublished findings into public spectacle.
- Preserve a clean separation between publicity and disclosure.
- Focus on clarity, scope, and trust.
