# Code Of Conduct

This repository is a public documentation surface for the Tau Ceti Project. Keep participation useful, calm, and safe.

## Expected Behavior

- Be respectful and direct.
- Keep discussion tied to documentation, public updates, or scan-ledger maintenance.
- Prefer evidence and clarity over drama.
- Respect maintainer requests about scope and redaction.

## Unacceptable Behavior

- Posting vulnerability details about third-party software here
- Sharing exploit code, private reports, credentials, or sensitive artifacts
- Harassment, abuse, threats, or intimidation
- Spam, marketing noise, or off-topic issue churn
- Attempts to pressure maintainers into disclosing unpublished findings

## Scope Enforcement

Maintainers may edit, lock, close, or remove content that:

- discloses security details that do not belong in this repo
- creates legal or operational risk
- violates the repo's documentation-only scope

## Reporting

If a thread or contribution crosses the repo's public-safety boundary, open a normal maintainer-facing issue only if the problem is about this repository's docs or process.

If the content is actually a third-party vulnerability disclosure, do not post it here.
