# Contributing

This repository is for public documentation, updates, and the public scan ledger only.

## Good Contributions

- README improvements
- clearer public-facing language
- typo and formatting fixes
- better documentation structure
- updates to `docs/scanned-repos.md`
- updates to `docs/updates.md`

## Out Of Scope

Do not contribute:

- vulnerability details
- exploit steps
- private research notes
- sensitive screenshots or logs
- raw findings about scanned repositories
- content that names specific flaws in third-party software

## Pull Request Rules

Keep changes small and readable.

Before opening a PR:

1. Confirm the change belongs in a public documentation repo.
2. Remove any technical detail that could disclose a third-party security issue.
3. Update related docs if the public policy or repo ledger changed.
4. Make sure the PR description explains the public-facing purpose of the change.

## Issue Rules

Use issues for:

- documentation corrections
- public-ledger fixes
- public update suggestions

Do not use issues for:

- vulnerability disclosure
- scanned-target findings
- requests for unpublished research details

See [SECURITY.md](SECURITY.md) before posting anything security-related.
