# Security Policy

## Scope

This repository is not a disclosure venue for third-party software vulnerabilities.

It exists to publish:

- public project documentation
- public project updates
- the names of repositories that have been scanned

It does not publish:

- target-specific vulnerability details
- exploit chains
- private reports
- unpublished findings

## Do Not Post Third-Party Vulnerabilities Here

Do not open a public issue or pull request that contains:

- a vulnerability report about another project
- reproduction steps for a security flaw
- exploit code
- sensitive evidence
- credentials, keys, tokens, or private artifacts

Those submissions are out of scope for this repository and may be removed.

## If The Problem Is In This Repository

If your concern is about this repository's own public content, documentation, or GitHub configuration, open a normal issue unless doing so would itself disclose sensitive information.

If the report would expose sensitive information, do not post it publicly.

## Disclosure Boundary

The public scan ledger in this repository lists repository names only. It is not a publication channel for findings.
